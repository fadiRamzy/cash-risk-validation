# أكواد الاستعلامات الائتمانية

نظام مرجعي داخلي لإدارة المخاطر — شركة كاش للتمويل متناهي الصغر، للبحث الفوري عن أكواد الاستعلام الائتماني الخاصة بالبنوك والشركات والمؤسسات المالية، مع جدول التقييم الائتماني (300–850).

## المزايا

- بحث فوري بالاسم أو الكود أو اسم البنك، بدعم كامل للعربية والأرقام، مع تمييز النص المطابق.
- تصفية حسب التصنيف (بنوك تجارية، تمويل متناهي الصغر، تأجير تمويلي... إلخ).
- سجل آخر 10 عمليات بحث، محفوظ محليًا في المتصفح.
- اختصارات لوحة المفاتيح: `Ctrl+K` للتركيز على البحث، `Esc` لمسحه.
- تصدير نتائج البحث إلى CSV أو PDF.
- جدول تقييم ائتماني تفاعلي (مقياس مرئي + جدول قابل للبحث والطباعة).
- الوضع الليلي/النهاري مع الحفظ التلقائي للتفضيل.
- يعمل كتطبيق ويب تقدمي (PWA) بدون اتصال بعد أول تحميل.

## هيكل المشروع

```
index.html                 الصفحة الرئيسية
assets/css/styles.css       التصميم والألوان
assets/js/app.js            محرك البحث والواجهة
assets/icons/               أيقونات PWA
data/codes.json             قاعدة بيانات الأكواد (المصدر الوحيد للبيانات)
data/rating.json             جدول التقييم الائتماني
manifest.json               إعدادات PWA
service-worker.js           التخزين المؤقت للعمل بدون اتصال
tools/extractor.html         أداة استخراج البيانات من ملف PDF جديد
```

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. من إعدادات المستودع: `Settings → Pages → Branch: main → root`.
3. الموقع سيصبح متاحًا على `https://<username>.github.io/<repo>/`.

## تحديث البيانات مستقبلًا

**الطريقة السريعة:** استخدم `tools/extractor.html` (افتحه في المتصفح)، ارفع ملف PDF الجديد بنفس التنسيق، ثم نزّل `codes.json` الناتج واستبدل به الملف الموجود في `data/`.

**تنسيق codes.json:**
```json
{
  "generatedAt": "2026-07-27",
  "totalRecords": 447,
  "records": [
    { "code": "01280001CB", "name": "المصرف المتحد", "category": "بنوك تجارية" }
  ]
}
```
لا حاجة لتعديل أي كود برمجي — يكفي استبدال الملف.

## جدول التقييم (data/rating.json)
كل عنصر يحتوي على `rating` (التقييم)، `min`/`max` (نطاق النقاط)، و`riskRate` (نسبة المخاطر %).

## الصيانة

- التصنيفات (فئات الجهات) يتم تحديدها تلقائيًا من الحرفين الأخيرين في الكود، عبر خريطة `CATEGORY_MAP` الموجودة في `assets/js/app.js` (وأداة الاستخراج). لإضافة تصنيف جديد، أضف السطر المطابق في كلا الملفين.
- الألوان والخطوط قابلة للتعديل من متغيرات CSS في أعلى ملف `styles.css`.
- عند تغيير رقم الإصدار، حدّث `CONFIG.version` في `app.js`.
