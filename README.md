# أكواد الاستعلام الائتماني المصري — نسخة موبايل/PWA

## الملفات
- `index.html` — الصفحة الرئيسية
- `styles.css` — التصميم (فاتح/ليلي، متجاوب بالكامل)
- `app.js` — كل المنطق + بيانات الـ192 جهة مدمجة داخله
- `manifest.json` — يخلي الموقع "يتثبت" كتطبيق (PWA)
- `sw.js` — Service Worker يخلي الموقع يشتغل بدون نت بعد أول فتح
- `vendor/fuse.esm.js` — مكتبة البحث الذكي (منسوخة محليًا، مفيش أي اعتماد على إنترنت لتشتغل الأساسيات)
- `icons/` — أيقونات التطبيق بمقاسات مختلفة

## رفعه على GitHub Pages
1. ارفع كل الملفات دي (بنفس الهيكل) في ريبو على GitHub.
2. من Settings → Pages، اختار الفرع (main) والمجلد (root)، واحفظ.
3. الرابط هيبقى شكله: `https://username.github.io/repo-name/`

⚠️ ملاحظة مهمة: لازم الملفات تتفتح عبر `https://` مش عبر فتح الملف مباشرة من الجهاز (`file://`)، لأن الـ Service Worker وميزة الـ Modules (`app.js`) محتاجين بروتوكول ويب حقيقي. GitHub Pages بيوفر ده تلقائيًا.

## تحويله لـ APK
دلوقتي الموقع جاهز لأي أداة تحويل PWA لـ APK زي:
- **PWABuilder** (pwabuilder.com) — الأسهل، بتاخد رابط الموقع وتطلعلك APK جاهز.
- **Bubblewrap** (من Google) — لو عايز تحكم أكتر في الإعدادات.
- **Median.co / GoNative** — لو عايز مميزات إضافية زي إشعارات push.

كل الأدوات دي هتقرأ `manifest.json` تلقائيًا وتاخد منه الاسم والأيقونة والألوان.

## المميزات الجديدة اللي اتضافت
- **تصميم متجاوب بالكامل** لأي مقاس شاشة موبايل، مع مساحات لمس مريحة (44px+) ودعم لـ "الحواف الآمنة" (notch / زر الهوم في آيفون وأندرويد).
- **شريط تنقل سفلي** (بحث / المفضلة / معلومات) بشكل تطبيقات الموبايل الحقيقية بدل السكرول الطويل.
- **وضع ليلي** بيتذكر اختيارك.
- **المفضلة** — تقدر تحفظ أي جهة بالنجمة وترجعلها بسرعة من تبويب "المفضلة".
- **يعمل بدون إنترنت** بعد أول فتح للموقع (بيانات + بحث كامل).
- **زر "تثبيت"** بيظهر تلقائيًا في أندرويد/كروم لتثبيت الموقع كتطبيق قبل حتى تحويله APK.
- نفس ميزات البحث والفلترة والنسخ وتصدير CSV اللي كانت موجودة، بس بشكل أسرع وأنضف على الموبايل.

## لو عايز تضيف بيانات جديدة
البيانات كلها في `app.js` جوه المتغير `BASE_DATA` — كل صف شكله:
```js
{id:193, name:"اسم الجهة", code:"CODE0001", category:"بنك تجاري", source:"أكواد الاستعلام 2025"},
```
لو التصنيف جديد مش موجود في `CAT_META` جوه `app.js`، ضيفله سطر لون وأيقونة زي الباقي.
